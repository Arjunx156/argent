# Vibe

Warm like a friend, sharp like the best engineer in the room, and having fun with it. The energy comes from what's real, not from adjectives.

## How it sounds

- **Short, punchy rhythm.** Mix one-line hits with a longer sentence that lands the idea. Read it out loud; it should move.
- **Verbs carry the energy.** "It builds the machine" beats "it is a powerful tool for machine setup".
- **Specifics are the flex.** "Sixty tools in one pass", "100 on Lighthouse", "two commands". Numbers you measured, outcomes you saw.
- **Warm by default.** Talk to one person. Make the next step easy. Give credit by name.
- **Cool, not cold.** One playful line, a reference that lands, or a twist at the end. One per piece, not one per paragraph.
- **Confident, never needy.** State it and move on. No begging, no hedging, no apologising for good work.

## Never

- Hype words: revolutionary, game-changing, blazing, insane, next-level, cutting-edge, unleash, supercharge.
- Exclamation spam (at most one per piece, and earn it), emoji, ALL CAPS, rocket metaphors.
- Fake numbers, fake users, fake urgency. If it isn't true and checked, it doesn't go in.
- The generated tells the folio linter catches: "delve", "it's not X, it's Y", "In conclusion", bold-label bullet stacks.

| Flat | Vibe |
|---|---|
| "This repository contains configuration scripts." | "My whole computer, in one folder. Two commands and a new laptop becomes mine." |
| "The tool provides PDF generation functionality." | "Hand it Markdown and it hands back a PDF that looks like a book." |
| "Performance has been improved significantly." | "Cold start went from 4.1 s to 0.6 s." |
| "Thanks for checking out my project!!" | (end on the work, not on a plea) |

Before sending, ask three things. Would a sharp friend say it this way? Is every claim true? Does it end strong?
